# 工作台 - 黄金交易

珠珠的黄金交易工作台,支持实时金价、交易记录、利润统计。

## 功能

- 💰 **实时金价** - 点击刷新获取最新金价
- 📈 **总览** - 总克重、总成本、总利润、利润率
- 📝 **交易记录** - 添加/删除交易,自动计算利润
- 📤 **导出/导入** - JSON 文件同步

## 访问

https://lisa2026p.github.io/taizhang/

## 用户切换

顶部点击头像切换:
- 💎 **珠珠** - 黄金交易
- 🐦 **菜鸟** - 账目记录

本地存储(localStorage),换设备需导出导入。
