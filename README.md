# 工作台 - 账目记录

一个手机友好的账目记录工具,支持按日期、账号、项目多维度统计。

## 功能

- 📋 **记录管理** - 添加/删除账目记录
- 📅 **按日期统计** - 查看每日汇总
- 👥 **按账号统计** - 查看各账号汇总
- 📁 **按项目统计** - 查看各项目汇总
- 📊 **总览卡片** - 实时显示总金额、总笔数、账号数、项目数

## 访问

https://lisa2026p.github.io/taizhang/

## 同步

两台手机手动同步:
1. 在手机 A 上点「📤 导出」→ 保存 .json 文件
2. 通过微信发给手机 B
3. 在手机 B 上点「📥 导入」→ 选择收到的文件
4. 导入自动合并,不会覆盖已有记录
